# Da Tommy — foto ottimizzate per il sito

Queste immagini sono state ridimensionate e salvate in JPEG ottimizzato per il web.
Sono foto reali ricevute per il progetto; i nomi dei file sono semplici da usare nell'HTML.

## File inclusi

- `ristorante-esterno.jpg` — Esterno e dehors
- `pizza-speciale.jpg` — Pizza speciale
- `pizza-classica.jpg` — Pizza classica
- `pizza-dolce-cuore.jpg` — Pizza dolce a cuore
- `pizza-olive.jpg` — Pizza con olive
- `insalata-caprese.jpg` — Insalata caprese
- `insalata-mista.jpg` — Insalata mista
- `tagliere-salumi-formaggi.jpg` — Tagliere di salumi e formaggi

- `pizza-margherita.jpg` — Pizza al pomodoro e mozzarella
- `pizza-dolce.jpg` — Pizza dolce
- `pizza-vegetariana.jpg` — Pizza vegetariana
- `pizza-burrata.jpg` — Pizza con burrata

## Como usar no site

Coloque os arquivos na pasta `images/` do repositório e referencie, por exemplo:

```html
<img src="images/pizza-classica.jpg" alt="Pizza classica Da Tommy" loading="lazy">
```

Nota: confira nomes, ingredientes e descrições antes de publicar legendas específicas.
